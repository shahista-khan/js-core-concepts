# JavaScript Fundamentals & Concepts

A structured repository containing core JavaScript practice files, concept guides, and code snippets ranging from basic syntax to intermediate data structures and logic.

## 📌 Topics Covered

* **Variables & Data Types:** Type conversions, type coercion, dynamic typing
* **Control Flow:** Conditional statements (`if-else`, `switch`), logical operators, loops
* **Data Structures:** Arrays, Objects, Complex/Nested Objects
* **Functions & OOP:** Function declarations, expressions, constructor functions, methods
